# ApeTek 1.3 toolbar, sliders, spacing, and rendering evidence

The single toolbar contains the chimpanzee logo, ApeTek / LATEX FOR APES wordmark, New/Open/Save/Save as/Settings, filename, Copy rendered, and PDF controls. The settings popup is anchored to its toolbar button. The existing palette and editor/preview panels remain intact.

Math size is a native 50–200% slider with integer steps, a live percentage output, arrow keys, pointer dragging, and a nonpassive native wheel listener. Line spacing ranges from 1–3 with 0.05 steps; paragraph spacing ranges from 0–40px. Fresh defaults are 100%, single line spacing, and 13px paragraph spacing. The core renderer's 12.75px base makes new 100% equal the former 75% physical math size.

Preferences use `apetek.preferences.v2`. A v1 size migrates once using `round(oldScale / 0.75)` clamped to 50–200, retaining page size/alignment and initializing spacing. Successful migration writes v2 and removes v1, so a later load does not apply the conversion again. Malformed data and storage errors remain safe.
